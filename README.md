# دانشنامه علم کوانتوم (QPedia.ir)

مخزن رسمی توسعه فنی، نگارش مقالات، دارایی‌های بصری و معماری وردپرس وب‌سایت **qpedia.ir**.

---

## 📁 ساختار پوشه‌ها و دسته‌بندی فایل‌ها

| پوشه / مسیر | محتوا و شرح | وضعیت |
|---|---|---|
| **`articles/`** | ۱۸ مقالهٔ جدید تألیف‌شده + ۹ بسته واردسازی و سئوی همراه (Markdown خالص) | ✅ آماده و استاندارد |
| **`plugin-13-articles/`** | ۱۳ مقالهٔ استخراج‌شده از افزونه (فرمت‌های MD ،HTML و دیتابیس JSON) | ✅ آماده و تفکیک‌شده |
| **`importer/`** | افزونهٔ استاندارد وردپرس (`qpedia-13-articles-importer.zip` و فایل PHP) جهت ورود به عنوان پیش‌نویس | 📦 آمادهٔ نصب در WP |
| **`images/`** | ۱۶۰ تصویر شاخص مربعی با سبک نئونی/سایبری یکپارچه برای کل مقالات | 🖼 آمادهٔ اتصال |
| **`docs/`** | اسناد مرجع، راهنمای نگارش، درختچهٔ کامل مقالات و گزارش وضعیت فنی سیستم | 📘 اسناد مرجع |
| **`theme/`** | کدهای ساختار پوسته فرزند (`quantum-pedia-child`) و استایل‌های اصلی | 🎨 کد پوسته |

---

## 📑 اسناد مرجع کلیدی (در ریشه و پوشه `docs/`)
1. **`00-دستورالعمل-مرجع.md`**: سند قوانین بنیادین، خطوط قرمز و قواعد نگارش (از جمله بند ۵.۱).
2. **`سند-فنی-و-وضعیت-سیستم.md`**: مشخصات فنی معماری سایت، وضعیت افزونه‌ها و قالب فرزند.
3. **`درختچه-کامل-مقالات-QPedia.md`**: نقشهٔ جامع مقالات منتشرشده و در صف با اسلاگ‌ها و وضعیت.
4. **`دستورالعمل-مقاله-نویسی-QPedia.md`**: اصول نگارش محتوا بر پایه Markdown خالص بدون CSS/HTML اضافی.
5. **`_editorial-registry.md`**: رجیستری پیوندها و خوشه‌های محتوایی.
6. **`CHANGELOG.md`**: گزارش تغییرات به‌روزشدهٔ مخزن.
