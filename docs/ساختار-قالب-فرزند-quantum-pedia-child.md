## ⚙️ ۲. تحلیل موشکافانهٔ فایل راه‌انداز (`functions.php`)

تمام تنظیمات حیاتی سایت در `functions.php` قالب فرزند متمرکز شده است:

### ۱) بارگذاری استایل‌ها و فونت‌ها (`qpedia_child_enqueue_assets`)
- بارگذاری زنجیره‌ای: `style.css` ➔ `qpedia-layouts.css` ➔ `custom.css` ➔ `custom.js`.
- تزریق مستقیم `@font-face` وب‌فونت‌های فارسی وزیرمتن (`Vazirmatn`) به تگ `<head>` با فرمت فوق‌سریع WOFF2 و ویژگی `font-display: swap`.

### ۲) ثبت انواع پست‌های اختصاصی (Custom Post Types)
- **`quantum_article` (مقاله‌های کوانتوم):** پشتیبانی از عنوان، ادیتور، تصویر شاخص، چکیده، بازبینی‌ها و فیلدهای سفارشی.
- **`quantum_scientist` (دانشمندان):** با آرشیو اختصاصی در مسیر `/scientists/` و قابلیت درج نام لاتین و مشخصات هویتی.

### ۳) ثبت تاکسونومی‌ها (Taxonomies)
- **`quantum_category` (دسته‌بندی موضوعی کوانتوم):** ساختار سلسله‌مراتبی (دسته اصلی و زیردسته) با نامک‌های مشخص.
- **`scientist_field` & `quantum_scientist_group`:** شاخه‌های تخصصی و گروه‌های دانشمندان.

### ۴) سیستم آدرس‌دهی تخت و ریرایت (Flat URL Structure & Rewrites)
- مقالات کوانتوم دارای آدرس تخت و فوق‌العاده تمیز سئو هستند: `https://qpedia.ir/%postname%/` (بدون پیشوند اضافی `/quantum_article/`).
- فیلتر `qpedia_child_filter_article_request` هوشمندانه درخواست‌های URL را به پست تایپ درست نگاشت می‌کند.
- ریدایرکت خودکار ۳۰۱ از مسیرهای قدیمی (`/glossary/`) به صفحه اصلی جهت حفظ رتبه سئو.

### ۵) بهینه‌سازی نقشه سایت (Sitemap Fix)
- فیلتر `wp_sitemaps_taxonomies` برای جلوگیری از خطای ۴۰۴ در تاکسونومی‌های بلااستفاده و هدایت بهینه‌تر کراولرهای گوگل.

## 🎨 ۳. راهنمای معماری استایل‌ها و فایل‌های CSS

| فایل CSS | وظیفه و محتویات |
|---|---|
| **`assets/css/qpedia-layouts.css`** | چیدمان‌های گرید، Flexbox، کانتینر پوسته (`.qp-shell`)، ساختار کارت‌های مقاله (`.qp-article-card`) و دانشمندان (`.qp-scientist-card`)، هدر، فوتر و ساختار صفحات تکی. |
| **`assets/css/custom.css`** | پالت رنگی سایبری (متغیرهای CSS مثل `--qp-bg`, `--qp-neon`, `--qp-text`)، استایل‌های نقل‌قول (`blockquote`)، جداول، خطوط نئونی، اسکرول‌بار سفارشی و حالت تاریک. |
| **`style.css`** | فایل شناسه چایلد تم با اعلام `Template: quantum-pedia`. |

## 🧭 ۴. نقشهٔ راه تغییرات آینده (برای هر تغییر کجا را ویرایش کنیم؟)

این جدول مرجع همیشگی شما برای ایجاد تغییرات بعدی است:

| نیاز یا تغییر مورد نظر | فایل یا فایل‌های هدف برای ویرایش |
|---|---|
| **تغییر استایل کارت شناسنامه دانشمندان / جداول / رنگ‌ها** | `assets/css/qpedia-layouts.css` و `assets/css/custom.css` |
| **تغییر ساختار یا بخش‌های صفحه اصلی (Hero، آمار، چیدمان مقالات)** | `front-page.php` |
| **تغییر هدر، منوی بالا، لوگو یا دکمه‌های ناوبری** | `header.php` |
| **تغییر فوتر، متن کپی‌رایت، لینک‌های پایین صفحه یا امضا** | `footer.php` |
| **تغییر چیدمان داخل صفحه مقالات (محل تصویر شاخص، TOC، باکس نویسنده)** | `single-quantum_article.php` |
| **تغییر چیدمان داخل صفحه دانشمندان (شناسنامه، نام لاتین، جایگاه تصویر)** | `single-quantum_scientist.php` |
| **تغییر صفحه آرشیو مقالات یا دایرکتوری دانشمندان** | `archive-quantum_article.php` یا `archive-quantum_scientist.php` |
| **تغییر صفحه دسته‌بندی موضوعی کوانتوم** | `taxonomy-quantum_category.php` |
| **افزودن تاکسونومی جدید، تغییر ساختار URL، توابع سئو یا کد PHP** | `functions.php` |
| **تعویض فونت سایت یا افزودن وزن‌های جدید** | پوشه `fonts/` و تابع `qpedia_child_enqueue_assets` در `functions.php` |
| **تعویض لوگو یا آیکون‌های سایت** | پوشه `assets/images/` |
