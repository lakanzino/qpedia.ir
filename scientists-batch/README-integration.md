# پیاده‌سازی پایهٔ جدید مدخلِ دانشمندان — راهنمای نصب

این بسته، قالبِ یکپارچهٔ مدخل‌های «دانشمندان کوانتوم» را پیاده می‌کند تا همهٔ مدخل‌ها یک شکل شوند:
**گریدِ شناسنامه + قلاب + روایت + نقل‌قول + گاه‌شمار + پرسش‌های آکاردئونی + منابع**.

## فایل‌ها

| فایل | کار |
|---|---|
| `qpedia-scientist.css` | استایل گرید، قلاب، نقل‌قول، گاه‌شمار و آکاردئون (متکی بر متغیرهای `:root` پوسته) |
| `single-quantum_scientist.php` | قالب تک‌مدخلی جدید؛ گرید را از متاها رندر می‌کند |
| `scientist-meta-box.php` | متاباکسِ ورود فیلدهای گرید + ثبت استایل (کد برای `functions.php`) |
| `einstein-sample-preview.html` | پیش‌نمایش مستقلِ طراحی (برای دیدن نتیجه پیش از نصب) |
| `einstein-content.html` | متن بدنهٔ وردپرسِ نمونهٔ اینشتین (آمادهٔ چسباندن) |

## مراحل نصب

1. **CSS:** محتوای `qpedia-scientist.css` را به انتهای استایل قالب فرزند اضافه کن
   (فایل `style.css` فرزند یا `assets/css/custom.css`).
2. **قالب:** فایل `single-quantum_scientist.php` را در ریشهٔ قالب فرزند جایگزین نسخهٔ فعلی کن
   (بکاپ از نسخهٔ قبلی بگیر).
3. **متاباکس:** محتوای `scientist-meta-box.php` را به `functions.php` فرزند اضافه کن.
4. در ویرایش هر مدخل، باکس «شناسنامهٔ سریع دانشمند» را پر کن؛ هر خانهٔ پرنشده خودکار از گرید حذف می‌شود.
5. متن بدنه (مثل `einstein-content.html`) را در ویرایشگر HTML بچسبان.

## ساختار ثابت هر مدخل (ترتیب پایانی)

قلاب (اپی‌گراف) ← گرید شناسنامه (از قالب) ← قلاب آغازین ← فصل‌های روایت ← نقل‌قول ← زندگی شخصی ← میراث ← کاوش بیشتر ← گاه‌شمار ← پرسش‌های آکاردئونی ← منابع.

## نکته‌ها

- بدنه بدون H1 (قالب H1 را از عنوان می‌سازد).
- پرسش‌ها با `<details class="qp-faq">` ساخته می‌شوند؛ بدون جاوااسکریپت (با لمس باز/بسته می‌شوند).
- گرید فقط از متاها می‌آید؛ متنِ نویسنده هیچ جدول/گریدی نمی‌سازد تا یکپارچگی حفظ شود.
